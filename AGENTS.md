# Instrucciones del proyecto

## Reglas generales

- Analiza primero el proyecto antes de realizar cambios.
- No modifiques archivos que no sean necesarios.
- No elimines funcionalidades existentes.
- Mantén la estructura actual del proyecto.
- No cambies tecnologías o frameworks sin autorización.
- Utiliza código sencillo, claro y mantenible.
- Antes de realizar cambios importantes, explica qué vas a modificar.

## Seguridad

- Nunca expongas contraseñas, claves API o credenciales.
- Valida los datos introducidos por los usuarios.
- Protege las funciones administrativas.
- No almacenes contraseñas en texto plano.

## Base de datos

- No elimines tablas ni columnas existentes sin autorización.
- Antes de modificar la estructura de la base de datos, explica el cambio.
- Utiliza consultas seguras y evita SQL Injection.

## Pruebas

- Después de realizar cambios, comprueba que las funciones existentes continúen funcionando.
- Si encuentras un error, explica primero la causa.
